# FUN-GAME
 fun, interactive command-line guessing game written in Python. Players can customize the number range and set their own difficulty by choosing the number of allowed attempts.
**Features**
• Custom Range: Define your own starting and ending numbers.
• Adjustable Difficulty: Choose how many attempts you want.
• Smart Hints: Tells you to guess higher or lower after every wrong turn.
**How to Play**
Prerequisites
Make sure you have Python 3 installed.
**Setup & Run**
1. Clone the project:bash
git clone https://github.com
Use code with caution.
2. Navigate to the folder:bash
cd YOUR_REPO
Use code with caution.
3. Run the game:bash
python main.py
Use code with caution.
